# MEDIMANCH Research Navigator V5

Final V5 build for the MEDIMANCH research cockpit.

## Environment variables
- `YOUTUBE_API_KEY` — existing YouTube API key.
- `OPENAI_API_KEY` — OpenAI API key stored only in Render environment variables.
- `OPENAI_MODEL` — defaults to `gpt-6-luna` in this package; set to another model available to your API project if needed.
- `PORT` — Render supplies this automatically.

## Start locally
```bash
npm install
npm start
```
Then open `http://localhost:3000`.

## Main workflow
1. MY KEYWORD or optional SIGNAL RADAR.
2. Flagship → Territory → Sub-category → Core Concept/Mechanism → Cluster.
3. Research selected node.
4. Current signals → Human tension → BIC → Viral angles → Visual video options → Titles.
5. Optional: Explore as Content IP. This branch never controls discovery quality.

## Safety/quality rule
Do not treat popularity as proof of efficacy. Do not turn traditional/creator/public discussion into medical efficacy claims. Premium/protocol analysis is optional and requires appropriate expert/evidence review.
