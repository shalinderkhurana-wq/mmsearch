# MEDIMANCH Research Navigator V5 — Final Architecture

## Purpose
A research cockpit that turns either a user-supplied keyword or an optional live-signal discovery pool into a navigable MEDIMANCH research universe, then drills into current signals, human tension, BIC, visual viral opportunities and final-layer titles.

## Two independent entry doors
1. MY KEYWORD — user already knows what to investigate.
2. SIGNAL RADAR — optional discovery pool built from live YouTube, Reddit public discovery and Google News RSS material. Radar never replaces the manual keyword path and never filters the research hierarchy.

## Core hierarchy
FLAGSHIP → CONTENT TERRITORY → SUB-CATEGORY → CORE CONCEPT / KNOWLEDGE HUB / MECHANISM → CONTENT CLUSTER → CURRENT SIGNALS → HUMAN TENSION → BIC → VIRAL ANGLES → VISUAL VIDEO OPTIONS → TITLES.

## Mechanism rule
The mechanism/process layer is explicit. If a responsible named mechanism/process is known, expose its name, simple explanation, confidence and verification need. Never invent a scientific name.

## Discovery integrity
Premium/course/business potential is never a gatekeeper. It must never reject, hide, down-rank, merge or distort a new discovery. Viral-only, series and Content IP outcomes are all valid.

## Optional Content IP branch
Only after a user deliberately clicks Explore as Content IP does the system analyze whether the selected knowledge can support a reusable Content IP Hub and possible assets such as a series, workshop, course, masterclass, podcast, documentary, program or community. This branch is downstream and independent of discovery quality.

## Research modes
- Research This Node: current selected-node scan.
- Go Deeper: second-order questions, mechanisms, Indian context, disagreements, edge cases and less-obvious visual opportunities.
- Research Again: same node, deliberately different research pass.

## Live research discipline
Discovery sources identify movement. Verification establishes facts. Popularity is not proof. Traditional use, creator repetition and public discussion are not automatically efficacy. Current trend claims are kept separate from evidence claims.

## Persistence
Browser local storage keeps the saved research shortlist, maps and optional Content IP hubs on that browser. This is an MVP persistence layer; a future database can make it cross-device.
